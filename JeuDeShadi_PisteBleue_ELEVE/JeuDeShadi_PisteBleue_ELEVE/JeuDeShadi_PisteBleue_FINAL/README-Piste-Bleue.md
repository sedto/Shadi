# Jeu de Shadi — Piste bleue

Cette version élève suit une progression d’accompagnement :

- étapes 1 et 2 : **très guidées** ;
- étapes 3 et 4 : **guidées** ;
- à partir de l’étape 5 : **autonomie accompagnée**.

Dans toutes les étapes, les méthodes et outils mis à disposition sont expliqués.
À partir de l’étape 5, l’algorithme n’est plus fourni : vous devez organiser vous-même les boucles, conditions et calculs nécessaires.

Consultez `Piste_Bleue_Jeu_de_Shadi.md` pour l’énoncé complet.
